# Состав резервной копии

В `backup.source` задаются `path`, `include` и `exclude`. Включение по умолчанию —
`["**"]`, исключение — `[]`. Явный пустой `include: []` означает отсутствие выбранного
содержимого, а не подстановку значения по умолчанию. Метаданные корня сохраняются.

```json
{
  "path": "${source}",
  "include": [".git/", "src/", "config/local.json"],
  "exclude": ["**/*.log", "src/cache/"]
}
```

Это фрагмент source, не самостоятельный конфигурационный документ.

## Правила

Пути относительно source, разделитель `/`, регистр учитывается. `*` означает ноль
или несколько символов внутри сегмента, `?` — один Unicode-символ внутри сегмента.
`**` занимает целый сегмент и означает ноль или несколько уровней. Поэтому
`**/*.log` соответствует и `root.log`, и `a/b/file.log`. Скрытые файлы обычные:
`**` включает `.git` и `.env`. `.gitignore` автоматически не применяется.

Совпавший включённый каталог включает поддерево; совпавшее исключение каталога
исключает поддерево. Завершающий `/` ограничивает совпадение каталогом. Исключение
всегда важнее включения. Неявного повторного включения через `!` нет. Остальные
символы, в том числе `[]` и `{}`, литеральные: это небольшой закреплённый glob-диалект,
не shell/minimatch. Абсолютные пути, `..`, пустые сегменты, NUL и встроенное `a**b`
отклоняются, а не нормализуются к другому смыслу. Начальное `./` допустимо.

Ссылка выбирается как сама ссылка; обхода её назначения нет. Выбор ссылки не
добавляет цель. Нужные родительские каталоги добавляются ради структуры и прав,
но не возвращают соседние исключённые файлы. Выбор пустого каталога сохраняет его.
Метаданные корня добавляются всегда. Ноль выбранных файлов виден в отчёте.

## Проверяемый результат

Сессия хранит `selected-files.nul` — точные относительные имена для упаковщика,
включая корень и каталоги без рекурсивного переобхода. NUL сохраняет имена с пробелами,
переводами строк и начальным дефисом. Шаблоны заново архиватору не передаются.

`selection-manifest.json` формата `workspace-recover/selection/v3` содержит пути,
типы, права, размеры, SHA256 обычных файлов и цели ссылок. Хеши считаются по реально
упаковываемым байтам. Inventory публикуется отдельно; recovery manifest содержит
его точный ID, размер и SHA256. Это не дополнительный файл внутри резервируемого
дерева. `info SESSION --type selection --view full` возвращает только его путь.

При восстановлении inventory скачивается и проверяется. Состав, права и байты
записей проверяются в общем extractor до запуска авторского workflow. При поздней
ошибке уже извлечённые записи сохраняются для расследования. Это не наблюдение за
последствиями тестов: после запуска тестов инструмент сам ничего не сравнивает,
не исправляет и не удаляет за автора.

Формат не обещает согласованный snapshot работающей БД. Его обеспечивает автор.
