# Контракт декларативных инструментов

Инструмент поставляется как отделяемый каталог с документацией, skill, готовыми
шаблонами значений и схемами. README сразу ссылается на skill. Агент заполняет
файл из поставки без предварительного вызова describe; describe остаётся доступен.

Модель: template + values → author manifest → frozen plan → session → receipt.
Потребитель сообщает намерение и неизвестные значения одним пакетом. Инструмент
сам выполняет механические шаги и сообщает одно следующее необходимое действие.
Interactive режим для человека открывает одну общую форму; non-interactive не
запускает диалог. Значения имеют типы, defaults и записанное происхождение.

Автор manifest задаёт весь workflow, включая tests и cleanup. Инструмент не
добавляет тесты, не выбирает subset, не анализирует посторонние изменения от тестов
и не назначает reset/rollback/cleanup за автора. Test warning не означает неудачу
восстановления. Явно объявленный cleanup выполняется в своём порядке/условии.

Backup проверяет recoverability собственным восстановлением через тот же engine
в новой OS-temp комнате. Внешний recovery manifest прикладывается к handoff;
payload не должен быть распакован, чтобы узнать правила его восстановления.
Успешную служебную комнату удаляет инструмент, warning/failure комнату сохраняет.
Это не разрешение очищать пользовательский target или исходный workspace.

Каждая backup/restore/init сессия имеет стабильный ID и сохранённые первичные записи.
Сводка сообщает ID и одну подсказку `More: workspace-recover info SESSION`.
`short` — сверхкраткий итог, `medium` — полезная доменная диагностика,
`full` — всегда только путь к первичному файлу. Это одинаково для success, warnings
и errors. Полная запись не заменяется summary. Reporting profiles выбирает автор
manifest; `info` читает сохранённые результаты, не запускает parser повторно.

Редактирование author manifest не инвалидирует старый plan. Новый запуск создаёт
новый plan, а continue использует замороженный план своей сессии. Версии собственных
форматов проверяются; одновременно поддерживается только текущий формат.

Skill учит использовать публичный declarative API, а не вручную воспроизводить
скачивание, склейку, распаковку и применение изменений. Успех integrity-проверки,
успех restore и результаты application tests — независимые факты.
